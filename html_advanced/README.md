# html_advanced

Building the **SmileSchool** landing page from a designer file (Figma), step by step.
This first project is about the HTML structure only: no CSS, no style, just semantic HTML.
The styling comes in the next projects.

![SmileSchool design](images/school_page.png)

## Page structure

All of the page lives in `index.html`:

| Task | Part | Main tags |
| --- | --- | --- |
| 1 | Header: clickable logo and 3 nav links | `header`, `div`, `a`, `img` |
| 2 | Banner: "Get schooled" and the 4 pros | `main`, `section`, `h1`, `p`, `button`, `h2`, `h3` |
| 3 | Quote from a student | `section`, `img`, `blockquote`, `p` |
| 4 | Most popular tutorials: 4 video cards with author and star rating | `section`, `h1`, `h2`, `h3`, `img` |
| 5 | Free membership: 4 items and a register button | `section`, `h1`, `h2`, `p`, `button` |
| 6 | F.A.Q.: 2 rows of 2 questions | `section`, `h1`, `h2`, `p` |
| 7 | Footer: logo, social links and copyright | `footer`, `div`, `a`, `img`, `p` |

## Learning objectives

- What HTML is, and what a markup language is
- How to create an HTML page from a wireframe
- What the DOM is
- What an element, a tag and an attribute are
- The purpose of each HTML tag used
